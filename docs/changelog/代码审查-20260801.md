# 代码审查-20260801

## 背景

Tier 0 初始实现完成后，对 `main` 分支上的全部应用代码运行 Bugbot 审查。因仓库仅有 `main` 分支、无 merge-base，审查采用 natural language 模式覆盖 65 个新增文件。

## 讨论过程

- Q: 审查范围？
- A: 后端 handler/protocol/database、前端 API 与页面、Docker 部署配置；设计文档与 Cursor rules 不纳入代码缺陷审查。

- Q: 发现多少问题？
- A: 6 项——2 个 High、4 个 Medium，均未修复，待后续迭代处理。

## 决策

按严重程度优先修复：

1. **P0（High）**：前端创建文档字段不匹配、后端任意文件读取
2. **P1（Medium）**：外键未启用、文档路由越权、API 路径错误、Sync 缺项目校验

## 审查发现

| 严重度 | 位置 | 问题 |

| High | `frontend/src/pages/Documents.tsx:156` | 创建文档表单提交 `content`，后端要求 `file_path`，功能不可用 |
