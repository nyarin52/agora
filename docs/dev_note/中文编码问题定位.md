# 中文编码问题定位

## 背景

Agora 后端 API 返回的中文在 PowerShell 终端显示乱码，但浏览器正常。

## 根因分析

两层问题：

1. **Go 后端**：Content-Type: application/json 缺少 charset=utf-8
   - PowerShell 收不到编码提示，默认用 GBK 硬解
2. **Cursor 编辑器**：设置中字体栈缺少中文字体，Cascadia Code/Consolas 中文覆盖不全
   - 部分汉字没有字形，显示为小方框

## 修复方案

### 后端（1 行）

    // base.go
    w.Header().Set("Content-Type", "application/json; charset=utf-8")

### Cursor 编辑器

    // settings.json
    "editor.fontFamily": "'Cascadia Code', 'Microsoft YaHei', Consolas, monospace"

## 附加发现

PowerShell 管道启动的子进程不会自动随父进程退出。曾有一个残留 Go 进程（PID 61268）占用 8080 端口，导致后续重启失败。
