# 鉴权方案设计

## 背景

用户建议 MVP 阶段不做鉴权。但 Web 管理后台运行在容器中，暴露到局域网或公网时没有鉴权是安全漏洞。

## 讨论过程

- Q: MVP 阶段是否需要鉴权？
- A: 不做用户登录系统，但做最轻量的 Token 认证。
- Q: 为什么不用 GitHub OAuth？
- A: OAuth 增加 100+ 行代码（登录、回调、token 刷新），MVP 阶段 Personal Access Token 足够。将来升级到 OAuth 只改 middleware 和登录页。

## 决策

### Token Middleware 方案

- 环境变量 AGORA_AUTH_TOKEN 控制：
  - 空值：middleware 直接放行（本地 localhost 使用）
  - 有值：所有 API 请求需带 Authorization: Bearer <token>
- 前端将 token 存 localStorage.agora_token，自动附加到请求
- 升级到 GitHub OAuth 时：只改 middleware + 登录页，数据库不受影响

### 代码量

- 后端：一个 middleware 函数（~20 行）
- 前端：API client 自动检查 localStorage（~5 行）
